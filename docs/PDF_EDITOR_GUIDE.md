# PDF Editor - User Guide

## Cara Menggunakan PDF Editor

PDF Editor adalah fitur visual yang memungkinkan Anda untuk mengedit PDF secara interaktif dengan preview halaman.

### Langkah-langkah:

1. **Pilih Tool "Edit PDF"**
   - Klik tombol "✏️ Edit PDF" di toolbar

2. **Upload File PDF**
   - Drag & drop file PDF atau klik untuk browse
   - Hanya 1 file PDF yang bisa diedit dalam satu waktu

3. **Klik "Open Editor"**
   - Setelah file ter-upload, klik tombol "✏️ Open Editor"
   - Editor akan menampilkan preview semua halaman

4. **Edit Halaman**

   **Delete Halaman:**
   - Klik icon 🗑️ pada halaman yang ingin dihapus
   - Halaman akan ditandai dengan badge "DELETED"
   - Klik icon ↩️ untuk restore halaman yang sudah dihapus

   **Rotate Halaman:**
   - Klik icon 🔄 untuk merotasi halaman 90° searah jarum jam
   - Klik berulang untuk rotasi 180°, 270°, atau kembali ke 0°
   - Badge akan menampilkan derajat rotasi

   **Reorder Halaman:**
   - Drag halaman dan drop ke posisi yang diinginkan
   - Urutan halaman akan berubah sesuai posisi baru

5. **Save Changes**
   - Klik tombol "Save Changes" untuk memproses
   - File PDF yang sudah dimodifikasi akan otomatis ter-download

### Tips:

- ⚠️ Anda tidak bisa menghapus semua halaman. Minimal 1 halaman harus tersisa.
- 🔄 Rotasi akan diterapkan pada file output final
- 🔀 Reorder halaman dengan drag & drop untuk mengatur ulang urutan
- 💾 Semua perubahan (delete, rotate, reorder) akan digabung dalam satu operasi

### Statistik:

Editor menampilkan statistik real-time:

- ✅ **Active**: Jumlah halaman yang masih aktif
- 🗑️ **Deleted**: Jumlah halaman yang akan dihapus

### Cancel:

Klik tombol "Cancel" untuk kembali tanpa menyimpan perubahan.
